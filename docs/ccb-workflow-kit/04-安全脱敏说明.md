# 安全与脱敏说明

## 本包明确未包含的内容

- OpenAI/Anthropic/OpenCode 的登录令牌、API key、refresh token、OAuth Cookie、设备码。
- `~/.codex`、`~/.claude`、`~/.config/opencode`、`~/.cc-switch` 的真实运行数据。
- `.ccb/agents/*/provider-state`、`provider-runtime`、session、PID、锁、日志、缓存、数据库。
- SSH 私钥、Git 凭据、`.env`、云厂商凭据、生产地址、真实项目路径、业务数据、历史对话。

## 可以安全共享的内容

- 本包中的 `*.example`、模板 `ccb.config`、普通 Markdown 教程和不含真实地址的 `AGENTS.md`。
- `ccb version`、CLI 版本号、匿名化目录结构和脱敏后的错误摘要。
- 从本包复制的 `skills/` 文件；它们只说明流程，不能替代登录和授权。

## 分享前的检查

在打包或发给他人前，在本包根目录运行：

```bash
./scripts/audit_bundle.sh
```

脚本只做关键字扫描，不能保证发现全部敏感内容。仍须人工确认：没有实际 API key、用户名/邮箱、内网 IP、项目客户信息、账号切换数据库或 provider 会话文件。

## 配置原则

1. 凭据只通过各 CLI 自己的交互登录、系统钥匙串或用户自己的安全环境变量提供。
2. `.ccb/ccb.config` 只描述布局、agent 与模型策略；不得写 literal token、key、密码或 `Authorization` 头。
3. 配置界面的 token 用环境变量或 owner-only 本地文件提供，不能提交到 Git。
4. 项目 `.gitignore` 忽略 CCB 运行态；只有团队明确决定共享的 `ccb.config`、`ccb_memory.md` 才可白名单提交。
5. 任一 agent 提示上传、粘贴或共享凭据时，停止操作，改用用户本人登录或请管理员在受控渠道授权。

## cc-switch 特别提醒

cc-switch 的账户/模型切换数据通常具有高敏感性。它是可选辅助工具，不参与 CCB 的项目拓扑。每位用户在自己的设备上从零配置；不要导出 `.cc-switch`、数据库、备份或日志，也不要把 cc-switch 的真实设置写进此包或 Git。
