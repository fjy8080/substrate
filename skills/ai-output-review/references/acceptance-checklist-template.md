# 绝对要素清单模板

按产出类别复制使用。每个要素一行，判定值 ∈ {通过, 不通过, 不适用(理由)}。

```markdown
## 要素清单：<产出类别>（run-id: <RUN-ID>）

| 要素 ID | 要素描述 | 判定 | 理由/证据哈希 |
|---------|----------|------|----------------|
| E-01 | <必须出现的最小完整单元> | | |
| E-02 | <必须覆盖的维度/段落> | | |
| E-03 | <必须遵守的格式/结构约束> | | |
| ... | | | |

通过率 = 通过 / (总项 − 不适用项)；达标线 100%。
```

## 编写守则

- 要素必须**可判定、可证伪**：写「包含 X 且单位为 Y」，不写「内容详实」「质量高」。
- 要素来自权威契约/设计文档的**显式要求**，不凭评审人偏好临时增加。
- 每个要素给出判定依据的取证方式（看哪个字段/哪段输出），判定时只允许依据登记过的取证方式。
- 清单本身随契约版本演进；评审记录里必须记清单版本号。

## 判定记录表（空白下发）

```markdown
| 样本 ID | 要素 ID | 判定 | 理由 |
|---------|---------|------|------|
| S-01 | E-01 | | |
```

样本 ID 与真实输入的对应关系只由评审组长掌握（脱敏要求）。
