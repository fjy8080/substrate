# 盲评规程（完整版）

配套 [SKILL.md](../SKILL.md) 的完整操作规程。

## 1. 角色模板

| 角色 | 人数 | 职责 | 任职要求 |
|------|------|------|----------|
| **评审组长** | 1 | 编排运行、去除模型标识与随机排序、汇总判定、维护判定记录表、封存证据 | 熟悉被评产出所属领域与验收清单 |
| **第一评审人（全量）** | 1 | 对全量样本逐要素判定，填写判定记录表 | 具备对应领域能力 |
| **第二评审人（抽样）** | 1 | 对 ≥1/3 抽样独立复评；与首评**背靠背**，不得先看首评结论 | 同上，且不得为第一评审人 |
| **严重事实错误复核人** | 2 | 对全部被判「严重事实错误」的样本独立复核，**100% 覆盖** | 可复用第一、第二评审人 |
| **裁决人（第三人）** | 1 | 对评审分歧作最终裁决 | 不参与前两轮评分 |

纪律：同一人不得同时担任第一、第二评审人；裁决人不得兼任前两者。角色指定完成前，任何「已达标」结论不成立。单人项目/小团队的最小可执行降级：第一/第二评审人可由两名不同的人（或用户本人 + agent）分别承担，但背靠背与 ≥1/3 抽样不可省略；彻底只有一人时，结论只能写「未完成独立评审」。

## 2. 交付前检查（评审组长）

1. 运行产出的评审材料**已去除 provider/model 名称**；
2. 样本顺序**已随机化**，且两次评审使用**同一随机序**（记录随机种子）；
3. 判定记录表为**空白模板**下发，不含任何历史结论；
4. 严重事实错误判定标准书面告知两位复核人。

## 3. 流程

```text
① 运行           真实模型全量跑一次，产出脱敏证据
      ↓
② 脱敏与去偏     去模型名 + 固定种子随机排序；原文只在受控环境（仓库外）留存
      ↓
③ 第一评审人全量  逐要素判定：通过 / 不通过 / 不适用（不适用须写理由）
      ↓
④ 第二评审人复评  按 ≥1/3 抽样，独立判定（背靠背）
      ↓
⑤ 严重事实错误    两位复核人对全部标记项 100% 复核
      ↓
⑥ 分歧裁决        分歧项交第三人裁决，裁决为终局
      ↓
⑦ 汇总与留痕      判定记录表入证据目录；结论分项给出，不出一句「整体达标」
```

## 4. 抽样规则（第二评审人）

- 抽样比例 **≥ 1/3**，向上取整；样本数 <3 时**全量复评**。
- 抽样须**覆盖全部产出类别**，且**强制包含**：
  - 所有被判「不通过」的样本（100% 复评）；
  - 所有被判「严重事实错误」的样本（100% 复评）；
  - 所有「不适用」判定的样本（理由须经复核）。
- 抽样方法书面记录（分层 + 固定随机种子），不得由第一评审人自主挑选。

## 5. 分歧判定与裁决

| 情形 | 处置 |
|------|------|
| 首评与复评一致 | 采信，记录 |
| 首评「通过」/ 复评「不通过」（或反之） | 计入分歧，交裁决人 |
| 任一方判「不适用」而另一方判「通过/不通过」 | 计入分歧，交裁决人 |
| 严重事实错误的认定不一致 | 计入分歧，交裁决人；**裁决前该样本按「存在风险」计入** |

裁决结果须写明依据（引用要素 ID 与判据条款），不接受「以多数为准」的简单表决。

## 6. 严重事实错误的认定

满足以下任一即计入，且**不因该样本其余要素表现优秀而豁免**：

- 结论性错误（把易混概念判反、把正确答案判为错误）；
- 会引导用户形成错误结论的解释；
- 会导致系统错误判分/错误决策的真值错误；
- 捏造输入未给出的条件（幻觉条件）。

**达标线**：严重事实错误率 **<1%**（按项目要求可收紧，不得放宽为「>0 也行」）。

## 7. 达标判定

| 项 | 达标线 |
|----|--------|
| 各类别要素通过率 | **100%**（不适用项不计入分母） |
| 严重事实错误率 | **<1%** |
| 可见性 | 新增要素须在最终界面**实际渲染**可见 |
| 评审完整性 | 抽样 ≥1/3 已完成；分歧已裁决；角色已指定 |

## 8. 常见盲区（真实教训沉淀）

- **mock 夹具测不出真模型行为**：mock 返回合法形状 ≠ 真模型会输出该形状；这是反复出现的盲区，合入前必须跑真模型 smoke 覆盖易触发形态。
- **「测试通过」先确认测的字符串真的是你以为的字符串**：断言可能匹配了错误目标。
- **可选嵌套字段校验失败 tolerate-drop**：输出 schema 中可选嵌套字段校验失败一律置空/跳过该段，不得 fail-closed 连坐整个主载荷。
- **单测全绿 ≠ 端到端同步**：自动化与端到端行为要分别验证。
